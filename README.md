# Generative AI Engineer Portfolio

This repository showcases various mini projects and fundamental concepts in Generative AI engineering. Below is a comprehensive overview of each project and the topics covered.

## Mini Projects

### 1. Deep Learning Fundamentals
- Introduction to Neural Networks
- Overview of Convolutional Neural Networks (CNN)
- Basics of Recurrent Neural Networks (RNN)
- Implementation of simple neural networks using Python and TensorFlow.

### 2. NLP Fundamentals
- Text preprocessing techniques
- Introduction to word embeddings
- Implementation of NLP models for sentiment analysis and text classification.

### 3. LangChain
- Understanding LangChain and its applications
- Building applications with LangChain API
- Examples and best practices.

### 4. RAG Systems
- Introduction to Retrieval-Augmented Generation (RAG)
- Implementation of RAG models
- Use cases and applications of RAG systems.

### 5. Streamlit Applications
- Creating interactive web applications using Streamlit
- Deploying Streamlit apps for showcasing machine learning models.

### 6. Chatbots
- Developing rule-based chatbots
- Creating AI-driven chatbots using NLP techniques
- Examples of various chatbot implementations in different domains.

## Conclusion
This repository serves as a learning hub for aspiring AI engineers, providing hands-on projects and foundational knowledge in generative AI.
